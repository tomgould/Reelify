# Roadmap

What Reelify does today is in [README.md](README.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). This page lists planned work only, in no particular order.

- A low-activity tier in the speed map, played faster instead of cut (for example 1x, 3x, 8x or cut)
- Keep quiet stretches that still have speech instead of cutting them as idle
- Tighter prompts for `--scoring deep`, so captions describe the activity and not the text on screen
- An interactive preview for choosing the idle threshold
- A web interface
- An SRT file from `analyse`, beside the JSON
- More vision providers
